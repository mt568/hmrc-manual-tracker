|  |  |
| --- | --- |
| **SRS Role**  **ETMP** | **Description** |
| Create / Cancel Repayments | HMRC users require a specific role to be assigned, in order to perform actions via the UI5 screen, to create and cancel MTD ITSA repayment requests. |
| Enter Repayment Bank Details | Allows an HMRC adviser to input new repayment bank details, for customers or agents.  Allows an HMRC adviser to amend or override existing bank details, for customers or agents.  Allows an HMRC adviser to input customer's bank details, to create a repayment. |
| ETMP ITSA PR Manually Raise a Charge | This allows the user to raise and amend manual late payment penalty charges and to create and amend Contract Notes via ETMP for ITSA customers. |
| High Value Repayment Approver | Approves high‑value repayments above a set limit Scheme of Delegated Authority (SoDA). |
| Initiate / Cancel Coding Out | Gives advisors the ability to create and cancel coding‑out requests for ITSA underpayments, via the UI5 application in ETMP. It is specific to coding-out only and does not allow creation or amendment of tax returns. |
| ITSA Claim to Reduce | The ITSA amend role, displays the ITSA taxpayer overview for the ITSA customer.  The HMRC user requires this role to be assigned, in order to access and edit certain fields of the form bundle only. They can view information such as master data, returns, as well as the functionality to process amendments to the value of the ITSA POA1 and POA2 items on taxpayers’ accounts, using the UI5 gateway service. |
| ITSA Manager | Manages the ITSA work queue and allocates work to staff.  **Cannot** be allocated with **ETMP ITSA Tax Officer**. |
| ITSA Ringfenced Category - Economic Crime - Access Role | Business individual category taxpayers, allowing HMRC tax officers to carry out all ITSA-related business processes, for taxpayers within this category.  This role must be paired with the 'RW1406 ITSA Ringfenced Category – Maintenance Role'. |
| ITSA Ringfenced Category - Expats - Access Role | The "ITSA Ringfenced Category – Expats – Access" role provides full access to ITSA Ringfenced Expats category taxpayers, allowing HMRC tax officers to carry out all ITSA-related business processes for taxpayers within this category.  This role must be paired with the 'RW1406 ITSA Ringfenced Category – Maintenance Role.' |
| ITSA Ringfenced Category - Foreign Entertainers Unit - Access Role | The "ITSA Ringfenced Category – FEU (Foreign Entertainers Unit) – Access" role, provides full access to ITSA Ringfenced FEU (Foreign Entertainers Unit) category taxpayers, allowing HMRC tax officers to carry out all ITSA-related business processes, for taxpayers within this category.  This role must be paired with the 'RW1406 ITSA Ringfenced Category – Maintenance Role.' |
| ITSA Ringfenced Category - Large Business Individual - Access Role | The "ITSA Ringfenced Category – Large Business Individual – Access" role, provides full access to ITSA Ringfenced Large Business Individual category taxpayers, allowing HMRC tax officers to carry out all ITSA-related business processes, for taxpayers within this category.  This role must be paired with the 'RW1406 ITSA Ringfenced Category – Maintenance Role’. |
| ITSA Ringfenced Category - Remittance Basis Charge - Access Role | The "ITSA Ringfenced Category – RBC (Remittance Basis Charge) – Access" role, provides full access to ITSA Ringfenced RBC (Remittance Basis Charge) category taxpayers, allowing HMRC tax officers to carry out all ITSA-related business processes, for taxpayers within this category.  This role must be paired with the 'RW1406 ITSA Ringfenced Category – Maintenance Role.' |
| ITSA Ringfenced Category – SARP SA Record Protection - Access Role | The "ITSA Ringfenced Category – SARP (SA Record Protection) Access" role, provides full access to ITSA Ringfenced SARP category taxpayers, allowing HMRC tax officers to carry out all ITSA-related business processes, for taxpayers within this category.  This role must be paired with the 'RW1406 ITSA Ringfenced Category – Maintenance Role.' |
| ITSARingfenced Category - Wealthy 1 - Access Role | The "ITSA Ringfenced Category – Wealthy 1 – Access" role, provides full access to ITSA Ringfenced Wealthy 1 category taxpayers, allowing HMRC tax officers to carry out all ITSA-related business processes, for taxpayers within this category.  This role must be paired with the 'RW1406 ITSA Ringfenced Category – Maintenance Role.' |
| ITSARingfenced Category - Wealthy 2 - Access Role | The "ITSA Ringfenced Category – Wealthy 2 – Access" role, provides full access to ITSA Ringfenced Wealthy 2 category taxpayers, allowing HMRC tax officers to carry out all ITSA-related business processes, for taxpayers within this category.  This role must be paired with the 'RW1406 ITSA Ringfenced Category – Maintenance Role.' |
| ITSA Super User | Sets up teams and assigns users to roles and structures. |
| ITSA Tax Officer | Allows the advisor to access the customer’s record and complete day‑to‑day actions on ETMP records.  **Cannot** be allocated with:  **RW1403**: ETMP ITSA Manager  **PC0032**: SAFE Repayment Approver  **PC0154**: ITSA Create / Cancel Manual Financial Adjustments |
| ITSA PR Penalty Processor | Allows advisors to manage penalty points and late payment / late submission penalties, using a dedicated SAP UI5 application. |
| ITSA PR Penalty View Only | View‑only access for penalty information. |
| ITSA View Only | View ITSA records only – no changes allowed. |
| Manual Financial Adjustments | Allows the adviser to manually add or cancel debit or credit adjustments.  **Cannot** be allocated with **ETMP ITSA Tax Officer**. |
| MTDB HIB Amend Opt Out | Enables an MTD user to opt out of 'quarterly submissions'. |
| MTDB HIB Amend | Used in conjunction with RT1402 ITSA Returns Amend. |
| MTDB HIB View | User can view customer data via the HIB / U15 |
| MTDB HiB Economic Crime Access | Enables the HMRC user to view Economic Crime customer records in HiB. |
| MTDB HiB Expats Access | Enables the HMRC user to view 'Expats' customer records in HiB. |
| MTDB HiB Foreign Entertainers Unit Access | Enables the HMRC user to view 'Foreign Entertainers' customer records in HiB. |
| MTDB HiB Large Business Access | Enables the HMRC user to view 'Large Business' customer records in HiB. |
| MTDB HiB Remittance Basis Charge Access | Enables the HMRC user to view 'Remittance Basis Charge' customer records in HiB. |
| MTDB HiB Wealthy 1 Access | Enables the HMRC user to view 'Wealthy 1' customer records in HiB. |
| MTDB HiB Wealthy 2 Access | Enables the HMRC user to view 'Wealthy2' customer records in HiB. |
| No Repayment Signal (NRS) | HMRC user's require this role to be assigned.   To maintain and have an option to edit the No Repayment Signal information. |
| Repayment Inhibit Worklist | The role will provide the user with access to a list of repayment work items, that an HMRC adviser will need to review.   These are cases where repayments are blocked or need further review. |
| RT1402 ITSA Returns Amend | Advisers will need this to amend MTD returns (quarterly or finalised returns).  Required with MTDB HIB Amend. |
| Safe Repayment Approver | Provides a HMRC user, authorisation to accept or reject a BACS, Payable Order or card repayment, that has been initiated by someone else.  **Cannot** be allocated with **ETMP ITSA Tax Officer**, or **ETMP ITSA Claim to Reduce** |
| SAFE Payment Allocations | This role provides authorisation to a HMRC adviser to search, view and maintain documents and transactions for customer accounts. |
