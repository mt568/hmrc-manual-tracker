As part of MTD, ITSA ETMP roles are available in SRS for you
to assign to your team.

When allocating roles, keep it simple — only give
the combination of ITSA ETMP roles, the user needs to carry out their
day-to-day job.

There are some ITSA ETMP role combinations that should not
be assigned together.

These restrictions are in place to reduce risk, support a
good customer service and help to reduce fraud.

### What you need to check before assigning roles

Not everyone will need the same level of ETMP access. Some
staff will need more roles than others and users can have a combination of:

• View access (read-only)

• Edit access (to make changes)

Before you submit a request, SRS
will indicate whether a business case is required to
support the allocation of these IT roles.

You need to consider:

• What does this person need to do in their role day-to-day?

• What access they need and why?

To avoid delays, try to include all required ITSA ETMP roles
for each user, in a single SRS request.

Where appropriate, bulk uploads will be done by CDIO.

### Roles and access

PT Operations - Line managers make requests via the Admin Team.

Other directorates
make requests via SRS and the instructions are below:

* Go to Browse SRS
* Go to User Management
* Add services for a single user
* Search by PID / name
* Request roles as per
  your Head of Duty
